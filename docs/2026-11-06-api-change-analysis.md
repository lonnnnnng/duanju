## 2. 规律

**频率**：24 天 11 次接口相关变动，约每 2.2 天一次；呈簇状（10-21~10-28 八天 6 次，
之后 9 天平静，11-06 再来一次）。

**振荡而非单向升级**：

| 能力 | 历史路径 |
| --- | --- |
| 播放 | 页面 HTML → `play-info` → `preload` → 签名 `v1` → 无签名 `v/` → 又签名 |
| 搜索 | 网页 SSR → 站点 API → App `search/tab`（签） → `fetch-debug`（免签） |
| 详情 | 签名 `video_detail/v1` → 免签 `multi_video_detail` → 又签名 |

**类型分布**：

| 类型 | 次数 | 说明 |
| --- | --- | --- |
| 签名/鉴权档位 | 4 | 最致命，统一表现 `200 + 0 字节` |
| 路径/载体迁移 | 5 | 换域名、换页面、换 API |
| 参数/版本号 | 3 | `vs_id_type=1`、`video_platform=1024`、`74232` |
| 响应结构/字段 | 3 | `video_model` 是字符串、搜索无封面、`bytevc2` |
| 风控/限流 | 3 | 固定 `device_id`→`110001`、`101116` 抖动、偶发空数据 |

**故障特征可判定**：

| 现象 | 含义 |
| --- | --- |
| `200 + 0 字节` | 网关拒绝：签名/档位不对，**或高频/偶发限流**（有效签名也会间歇出现） |
| `200 + 53 字节 code=101116` | 业务抖动，退避重试可恢复 |
| `200 + HTML` | 页面改版，解析路径失效 |
| `404` | 页面只公开部分分集 |

**稳定性排序**：首页 `bookmall/tab`（10-27 至今未变）> 站点 player 页（一直可用，但只覆盖前几集）
> 详情 > 搜索 > 播放取流（5 次，最不稳）。

## 3. 对方案的影响

复核历史差异后，撤回“仅 1 次需要代码、覆盖约 90%”的估算。路径、参数、已有签名档位和有限重试适合配方；HTML/JSON 迁移、POST 请求体签名、新密钥格式、音视频分离需要宿主已有相应适配能力。

当前采用配方引擎与内置适配器，暂不引入动态类加载。多 provider 必须先验证可用性和响应模型，不能仅配置历史 URL；新的算法或协议仍通过代码实现与 APK 发布。完整证据、修复与动态扩展评估见 [配方修复与动态扩展评估](2026-11-06-recipe-hardening.md)。

实现见 [android-app.md §2.2.2](android-app.md#222-接口配方l1--签名原语l2)。
