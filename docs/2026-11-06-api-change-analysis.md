## 2. 规律

**频率**：10-14 ~ 10-22 共 9 天 5 次接口相关变动，约每 2 天一次；10-21/22 两天连续两次
（签名升级 + 搜索载体迁移），呈簇状。

**振荡而非单向升级**：

| 能力 | 历史路径 |
| --- | --- |
| 播放 | 页面 HTML `_ROUTER_DATA` → 站点 `play-info` → `preload/v1` → 签名 `multi_video_model/v1` → 站点 `play-info`（2026-11-11 重新提为首选） |
| 搜索 | 网页 SSR → 站点 `/api/search/result` |
| 详情 | 签名 `video_detail/v1` → 站点 `play-info` |

**类型分布**：

| 类型 | 次数 | 说明 |
| --- | --- | --- |
| 签名/鉴权档位 | 1 | 最致命，统一表现 `200 + 0 字节` |
| 路径/载体迁移 | 2 | 换域名、换页面、换 API |
| 参数/版本号 | 1 | `vs_id_type=1`、`video_platform=1024`、`dr_scene=preload` |
| 风控/限流 | 1 | 固定 `device_id`→`110001`、偶发空数据 |

**故障特征可判定**：

| 现象 | 含义 |
| --- | --- |
| `200 + 0 字节` | 网关拒绝：签名/档位不对，**或高频/偶发限流**（有效签名也会间歇出现） |
| `200 + HTML` | 页面改版，解析路径失效 |
| `404` | 页面只公开部分分集 |

**稳定性排序**：首页 `bookmall/tab`（10-27 至今未变）> 站点 player 页（一直可用，但只覆盖前几集）
> 详情 > 搜索 > 播放取流。
