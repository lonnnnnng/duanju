# 安卓全页面细节优化与验收（2026-11-07）

## 1. 范围与结论

本轮保持现有 Cinema Day / Cinema Noir 风格，检查首页、搜索页、搜索结果页、详情页、普通播放页、全屏播放页、历史页和设置页。主要修复状态与恢复路径、浅深色可读性、触摸区域和小屏/大字体排版，没有改动接口配方、签名、重试次数或缓存淘汰策略。

已完成源码修改、离线回归、Lint、Debug 构建以及 Redmi Note 8 Pro / Android 16（API 36）真机覆盖安装。最终安装版本仍为工作区 `0.1.36` / code 22，未创建发布版本。

## 2. 逐页修改

| 页面 | 修改与目的 |
| --- | --- |
| 首页 | 刷新使用独立的请求游标，成功后才替换分页状态；刷新失败保留已显示内容和旧游标，并提供明确的刷新重试。分页失败仍重试失败页。重建后保留筛选项；迟到回复不能操作新视图。小屏或大字体用两列卡片。搜索入口保持 40dp 可见高度，触摸区扩大至 48dp。 |
| 搜索页 | 搜索历史改为可滚动容器；清空后恢复焦点和键盘；历史词、清空和返回操作有更充分的触摸区域。胶囊可见尺寸保持紧凑。 |
| 搜索结果页 | 失败与真实空结果分开，失败提供“重新搜索”；输入变化仍取消并拒绝旧回复。页面重建后恢复已提交关键词并重新加载结果，不退回搜索历史。次级信息、评分和提示文字使用配对主题色。 |
| 详情页 | 标签可换行；选集、分组、简介展开和返回操作更易点按；播放按钮保持原有紧凑可见高度。相关剧集请求失败不再缓存为“空列表”，允许点击重试。不可播放集使用主题禁用底色并说明状态。 |
| 普通播放页 | 分组点击读取实时当前集，修复播放后切换分组时高亮回到初始集。修复切换 InsetDrawable 后内边距被重置、分组胶囊过窄的问题。取流或解码失败停止转圈，保留错误原因，并在视频内提供“重试本集”；重试保留当前集和可用续播位置。预取状态刷新不能覆盖本集失败原因。 |
| 全屏播放页 | 系统返回先退出全屏，第二次才离开播放页；视频尺寸迟到时同步朝向。悬浮顶栏和底部工具栏避让系统栏/刘海安全区。全屏标题继续使用固定白色；静音、倍速、全屏按钮的无障碍说明与状态同步。底部进度条与工具栏继续保持同一个 48dp 容器、同时显隐。 |
| 历史页 | 保留“当前集 / 全剧总集数”的进度含义；补充无障碍“删除播放记录”操作和空态“去首页看看”。底部导航同步选中语义、提高未选文字对比度。 |
| 设置页 | 行高随文字增长，底部为悬浮导航留空间；开关整行可点，白色圆点有细描边。版本检查防重复请求，离开页面后不突然弹窗，销毁视图后拒绝迟到回调。配方与缓存占用显示绑定当前视图。缓存上限校验有限数、最小 128MB 和 Int 范围，不静默钳制；非法输入保留弹框与原值，用框下错误文字避免气泡遮挡按钮。 |

共用选集网格根据屏宽和字体倍率计算 3–6 列，保证常规 393dp 六列、320dp 五列、320dp/1.3 倍字体四列。主题中浅色导航图标配置限定到 API 27+，API 24–26 采用深色系统导航底色以保证旧版浅色图标可见。

主要实现位置：`LibraryFragment.kt`、`SearchActivity.kt`、`DetailActivity.kt`、`PlayerActivity.kt`、`SettingsFragment.kt`、`HistoryFragment.kt`、`MainActivity.kt`、`EpisodeGroups.kt` 及对应布局/主题资源。
