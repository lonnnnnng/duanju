# 播放、下载与合并

## 在线播放

播放窗口支持分集、画质、倍速、全屏、自动下一集、预缓存和续播。桌面支持键盘操作；手机支持上下滑动切集、横竖屏播放和方向感应。

原始 MP4 / HLS 播放和客户端直连受“系统设置”中的播放选项控制。直连条件不满足或失败时会回退到服务端中转。解密、换封装及音视频转码分别受并发限制；减少并发不会中止已经开始的任务。

播放来源包括在线内容、Emby、本地已下载文件和在线缓冲。浏览器 Cookie 对应的观看记录会自动保存播放进度。

## 下载任务

新任务可选择“最高可用”或指定画质。任务会保存所选画质，并在服务重启后恢复；下载完成后会检查视频流、尺寸和时长。程序保留源站提供的分辨率，不会生成源站不存在的画质。

下载页支持暂停、继续、取消、重试、优先级调整、补充新集和文件校验。暂停会保留已完成分集；清理任务记录不会删除视频，删除资源操作会移除选中的本地视频文件。

## 合并

合并在后台执行，刷新或关闭网页不会中断。兼容的分集优先复制或无损换封装，只有必要时才处理不兼容分集。合并后可播放本地全集，也可在成功后选择删除分集文件。

每部剧可开启“下载齐后自动合并”。程序会保存本轮完整章节集合，只有全部分集下载成功并通过视频校验后才开始合并。自动合并保留分集，并可在重启后恢复未完成任务。新章节会触发新一轮合并；用户取消或删除的任务不会自动重建。

自动合并在全集旁保存 `.duanju-merge.json` 收据，记录分集集合及成品哈希，用于中断恢复校验。同名旧全集缺少收据、分集集合变化或成品被改写时，程序会保留文件并提示处理，不会将旧文件当作本轮结果。

## 磁盘空间

后台下载、合并和入库复制默认预留 2 GiB 安全余量，并计入已知下载、合并分集和复制文件所需空间。处理期间会继续检查目标磁盘。空间不足时任务等待并定时重试；空间恢复后自动继续。等待中的合并可在重启后恢复。

默认下载目录是 `downloads/`，由 `-out` 或 `DUANJU_OUTPUT_DIR` 配置。已创建的任务继续使用任务保存时的路径。
