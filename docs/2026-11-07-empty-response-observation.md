## 能排除和不能下的结论

- 详情和分集 ID 读取成功，失败发生在取流正文解析之前；与播放器解码、预取取消无关。
- 设备与电脑时钟约差 1 秒；每次实际发送都会重新生成时间戳和签名，没有发现重用旧签名的证据。
- 同分集在电脑成功且随后在手机出画，说明该样本并非整体不可用。
- 两端身份、HTTP/TLS 栈和可能的网络出口并未统一，不能据此断言是身份封禁、限流或某个特定签名字段错误。
- `empty` 检查是 `text.isBlank()`；手机日志没有逐次原始正文或响应头，不能把它冒称为逐次 0 字节抓包证据。电脑对照有完整请求与原始响应。
- 当前重试能恢复部分暂时空响应，仍可能耗尽全部预算。未据此增加重试次数、轮换设备身份或激活未经验证的历史接口。
