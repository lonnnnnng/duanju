# Emby 同步

在主导航的“Emby设置”中配置自动同步。Emby 媒体库应能访问短剧发布的输出目录；在线分集模式还需要 Emby 能访问短剧服务的播放地址。Emby 地址和 API Key 可选，用于通知媒体库扫描及重试失败的扫描请求。

## 同步模式

### 已合并全集

开启“只同步已合并的全集”后，成功合并的本地视频会发布到 Emby 目录，例如 `Season 01/S01E001.mp4`，并生成 NFO 和海报。Emby 直接读取本地文件，因此短剧服务停止后仍能扫描和播放。该模式不会发布未完成的合并结果。

程序优先在同一文件系统创建硬链接；不支持硬链接、跨磁盘或文件权限不适合共享时，会复制到临时目录后再发布。原始下载文件保持不变。删除源全集或切换同步模式后，下一轮同步会撤下校验匹配的程序生成文件；原下载文件和自定义海报会保留。

配置扫描通知后，合并完成会立即安排同步和扫描；定时同步用于补查及重试。面板分别显示文件发布和 Emby 识别状态。Emby 识别状态不代表实际账号权限或编码兼容性，播放仍由 Emby 账号和媒体库配置决定。

### 在线分集

追剧或下载记录范围内的剧集可按分集同步，生成 HTTP STRM 和 NFO。播放需要短剧服务在线；已下载的分集优先使用本地文件，其余分集可在线播放。手动 ZIP 导出也使用 HTTP STRM / NFO。

## 共享目录权限

如果短剧和 Emby 由不同 Linux 用户运行，需要为 Emby 授予入库目录的遍历和读取权限。宿主机 systemd 部署可使用 [`scripts/configure-emby-permissions.sh`](../scripts/configure-emby-permissions.sh)，细节见[目录权限说明](emby-permissions.md)。不要对整个下载目录执行无条件的 `chmod -R 777`。

关闭自动同步只会停止后续更新，不会删除已有导出文件。Emby 中手动删除的入库副本，在仍符合同步范围时可能再次发布。
